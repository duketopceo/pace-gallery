# Brand assets

These are the **existing interim Pace v5 "Master Clock" marks**, copied unchanged from
`duketopceo/Pace-Server` (`brand/mark/`, `brand/wordmark/`, `brand/favicon/`). No new logo was drawn
for this repository. A human designer is expected to replace the interim paths in Pace-Server; when
that happens, re-copy these files (keep the viewBox and ids).

Construction: a vertical baton and a broken dial (the Swiss railway clock face) with one vermilion
`#D33C11` disc, the signal. The disc is the only chromatic element.

| File | Use |
|---|---|
| `pace-mark-32.svg` | Mark on light backgrounds (`currentColor` graphite) |
| `pace-mark-reversed.svg` | Mark on dark backgrounds |
| `pace-wordmark.svg` | Wordmark |
| `pace-lockup-horizontal.svg` / `-reversed.svg` | Mark and wordmark side by side |
| `logo-preview.png` | Render of the horizontal lockup on porcelain, for review |

`public/favicon.svg` is the Pace-Server favicon (it follows `prefers-color-scheme`).
